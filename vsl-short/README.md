# VSL curta — Story System (9:16, ~55 s)

Vídeo vertical para Reels/TikTok, montado sobre a narração com os silêncios removidos
(60,7 s → 55,0 s) e legendas sincronizadas palavra a palavra.

## Mídia (não versionada)
- `public/narracao.mp3` — narração já sem silêncios (pausas encurtadas para ~70 ms; respiro curto no corte "era—")
- `public/img/tiktok.png`, `public/img/instagram.png` — capturas dos perfis
- `public/logo.png` — logo do Story System (recortada, fundo transparente)

## Rodar
`npm install && npm run audio && npm run render` (usa o mesmo node_modules do projeto `vsl-story-system`, via link simbólico)

## Cenas

| 51–55,4 s | CTA: link da bio tocado + botão |
